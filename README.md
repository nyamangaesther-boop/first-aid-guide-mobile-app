First Aid Mobile App
Project Description

The First Aid Mobile App is an educational and emergency assistance application designed to provide users with quick, reliable guidance during medical emergencies. The app includes detailed instructions for handling situations such as bleeding, fractures, fainting, choking, burns, CPR, poisoning, and snake bites. It is ideal for students, healthcare trainees, and anyone seeking to be prepared for first aid scenarios.

This project was developed as part of a mobile application development course and demonstrates both front-end design and back-end functionality integration using Android Studio.

Features
Step-by-step instructions for common first aid emergencies
Interactive UI with clear visuals and text descriptions
Multimedia support for images and diagrams
Simple navigation for quick access in urgent situations
Technologies Used

IDE: Android Studio
Database: SQLite (if any data storage is implemented)
